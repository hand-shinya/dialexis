# sim2 — 結果の中身を判定する擬似利用者シミュレーション（2026-10-21）

過去の tools/sim（2026-10-13〜14）は、Actor（LLM）が画面の文字と押せる物の一覧を見て手を選び、
Checker が行動量（空転・到達・記録）を数えた。**結果の中身（正しい対象か・写しか・定型文か・行き止まりか）を
判定するオラクルが無かった**ため、所有者が実操作で見つけた欠陥12件をどれも検出しなかった。

sim2 は、3人の専門家（人間の作業シナリオ・シミュレーション理論・UI）の螺旋型の検討（2巡＋止揚）で決めた次の形をとる。

- **合否は決定論のオラクルだけ**（LLM に出させない）: O1 地図の見え方と待ち時間／O2 定型文（語を伏せ字にして他の語と同じ文・パネル内の反復・関係の根拠文0）／O3 別の見方の写し／O4 同一性（一次資料の正解札と照合: 転送・記事なし・曖昧さ回避）／O5 文脈の喪失・行き止まり／O6 CSS などの漏出／O7 多言語の並び／O8 経路の可視性と到達（中心を変えずに広げられるか・はみ出し・タッチ）
- **5人は規則で動く**（personas.js）: ①連鎖して掘る人（所有者の型・1366x768）②幅で総点検する人（1920）③取り違えを探す査読者（正解札のある語）④多言語の研究者（英語の画面）⑤時間の無いスマホの人（390・タッチ・15秒）。次に進む語は「地図の重みが最大の人物・著作・原語」。失望は止める条件にせず記録のみ。
- **実際の画面操作だけ**（driver.js）: hover・クリック・円形メニューの項目。内部の関数を直接呼ばない。
- **オラクル自身を試す**: selftest.js（悪い例で FAIL を出せるか）と、修正前の版（3d03585）での較正（既知欠陥の再現）。
- **正解札**（truth.py）: ja.wikipedia の実際の記事（転送・有無）と P31 を走行の前に一次資料から取る。外部へは1秒1件以上あけ、429 は待って再試行。

使い方: `node personas.js <chain|sweep|identity|multi|phone> <baseURL> <outdir> [語...]` → `node analyze.js <outdir> <truth.json> --json out.json`

**撤退**: 2026-11-04 に、記録した版の上で既知欠陥を1件も再現できないオラクルは削除する（専門家の合意）。
**主張してよい範囲**: この版・この語・この方策で、どのオラクルが何件発火したか。既知欠陥のうち何件を機械で再検出できたか。
**主張してはいけないこと**: 欠陥が無い／探究の役に立つ／利用者が納得する／語の範囲を超えた一般化。

## 2026-10-22 追加: O9 黙って消えた情報／O10 件数の無い畳み（completeness.js）
所有者の原則「サービス側が必要・不要を先に分けて出さないのは危険。全部出して利用者が取捨選択する」を機械で守らせる。
サーバが返した項目（意味・多言語・原語・人・型つき関係・埋没・転送先・別の記事・字）が、画面のどこか（畳んだ中も含む DOM の文字）に在るかを照合し、
無ければ O9。畳む見出しに件数が無ければ O10。語のカードが出ていない画面は「観測できず」（空の画面で全件を欠落と数えた誤りの再発防止）。
`node completeness.js <baseURL> <out.json> 語...`。変異（全体像の関係を16件で切る）で O9 が3件出ることを確認済み。
