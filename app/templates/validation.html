{{ '最初の5分：再現手順' if lang == 'ja' else 'First five minutes: reproducible path' }}

{% if lang == 'ja' %}
  1. Karl Marx の意味Mapを開く。人物として認識され、中心・分野・著作・概念・受容の層が表示されることを確認する。
  2. 地図上の 吉本隆明 などの関連人物を選ぶ。最初のメニューに 中心命題との関係 が出て、中心人物との歴史・著作・思想上の経路と証拠階層が説明されることを確認する。
  3. 地図上の 共産党宣言 を選ぶ。メニューの 著作の系譜 を開き、原題 Manifest der Kommunistischen Partei、成立条件、後続の問いが表示されることを確認する。
  4. 人物または関連語のメニューから 別の語と組み合わせる を選び、吉本隆明 を入力してAND検索する。結果が空でも停止せず、何が未取得・未確認かと次の探索入口が表示されることを確認する。
  5. 非有機的肉体を開く。語・短句・原語・翻訳・受容史を分け、候補と証拠を混同しない表示になっていることを確認する。
  6. スマートフォンの縦画面で同じ操作を行う。メニュー・結果面の主要ボタンが画面外へ逃げず、処理中表示、閉じる、戻る、次の提案が操作できることを確認する。
{% else %}
  1. Open the Karl Marx meaning Map. Confirm that the person is recognized and the map exposes identity, works, concepts and reception layers.
  2. Select a related person such as 吉本隆明. Confirm that the first menu item is Relation to the central proposition and that it explains routes and evidence levels.
  3. Select 共産党宣言. Open Work lineage and confirm the original title Manifest der Kommunistischen Partei, conditions of composition and further questions.
  4. Choose combine with another term and enter 吉本隆明 for an AND search. Even when results are empty, confirm that the screen explains what was not retrieved and leaves the next entry point.
  5. Open inorganic body. Confirm that term, short phrase, original form, translation and reception are separated, with candidates distinguished from evidence.
  6. Repeat the path on a smartphone in portrait orientation. Confirm that menus and result panels remain usable, show processing state, and retain close/back/next-action paths.
{% endif %}

{{ '合格と判定する観察点' if lang == 'ja' else 'What to observe for a pass' }}

{% if lang == 'ja' %}
  • 操作の途中で画面が空白・停止にならない。
  • 処理中は「処理中／探索中／構成中」が見え、待機と停止を区別できる。
  • メニューの文言と実際の結果が一致する。
  • 失敗・空結果・外部情報源の遅延が説明され、次の行動が残る。
  • 候補・書誌確認・本文確認・解釈・未確認が区別される。
  • 戻る・閉じる・別の見方・組み合わせで探索が再開できる。
{% else %}
  • The screen does not become blank or stop mid-operation.
  • Processing is visible as processing, searching or constructing.
  • Menu wording matches the result that opens.
  • Failures, empty results and slow sources are explained with a next action.
  • Candidates, bibliographic checks, text checks, interpretation and unverified claims are distinct.
  • Back, close, alternative views and combine reopen a path of inquiry.
{% endif %}

{{ '判定の境界' if lang == 'ja' else 'Boundary of the validation' }}

{% if lang == 'ja' %}

自動抽出は証拠ではなく候補です。グラフは真理の地図ではなく探索レンズです。第三者検証で「壊れない」「次に進める」ことを確認しても、原典の意味・翻訳の正確さ・影響関係そのものが自動的に確定したことにはなりません。そこは原典・版・訳者・標準ロケータを人間が照合してください。

現在の公開状態：IP直打ちのHTTP検証版です。スマートフォンの通常ブラウザでは表示・操作できますが、HTTPS化前にAPIキーや秘密情報を入力してはいけません。ドメイン取得後のHTTPS化が、広い告知と本格的な第三者利用の前提です。

{% else %}

Automatic extraction is a candidate, not evidence. The graph is an exploration lens, not a map of truth. A successful UI validation does not prove the meaning of an original, a translation or an influence relation; humans must still compare original text, edition, translator and standard locator.

Current public state: this is an IP-address HTTP validation instance. It is usable in an ordinary smartphone browser, but do not enter API keys or secrets before HTTPS is configured. Domain-based HTTPS is required before broad announcement and full third-party use.

{% endif %}
