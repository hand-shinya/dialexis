source の提示

Dialexis は AGPL-3.0 で配布されています。 network 越しに使う人も source を受け取れます。

source をdownloadする（tar.gz）

何が入っているか

  • application の source 一式（Python・JavaScript・template・style・試験）
  • licence 全文（AGPL-3.0）
  • 配備の手順と検証の script

何が入っていないか

  • version 管理の履歴（commitの文・著者情報・日付）
  • 運用の秘密（鍵・token・接続先・環境変数の値）
  • 稼働中のdata（利用者が作った企画・node・出典）
  • 外部情報源の実data（各情報源の利用条件に従って各所で取得してください）

履歴を含めないのは、履歴が source ではないからです。 AGPL-3.0 が求めるのは、この版を動かすための source です。

Source

Dialexis is distributed under AGPL-3.0. Anyone using it over a network can obtain the source.

Download the source (tar.gz)

Included

  • The application source (Python, JavaScript, templates, styles, tests)
  • The full licence text (AGPL-3.0)
  • Deployment steps and the verification script

Not included

  • Version-control history (commit messages, authorship, dates)
  • Operational secrets (keys, tokens, endpoints, environment values)
  • Live data (projects, nodes and provenance created by users)
  • External source data (fetch it from each source under its own terms)

History is not source. AGPL-3.0 asks for the source needed to run this version.
