境界宣言

  • 人類の知を網羅する装置ではない。
    接続された情報源と登録された研究痕跡の範囲だけを扱う。
  • 自動抽出は証拠ではなく候補。

  • グラフは真理の地図ではなく探索レンズ。

03

UI状態契約：停止しないことを構造にする

過去の失敗は個別ボタンの不具合ではなく、操作・非同期応答・画面履歴・解除・復旧の共通契約が欠けたことで発生した。現在は単一dispatcherへ集約している。

dispatcher single path
01 INPUT対象を受け取る

語・人物・著作・組み合わせ・分野・現在のview stateを正規化。

02 PLANActionを選ぶ

ACTIONS registryから同じAction IDを通し、surfaceごとに作用を再実装しない。

03 PENDING処理中を見せる

グレー文字だけでなく、処理中・探索中・構成中と待機を可視化。

04 SETTLE成功 / stale / error

古い応答を捨て、途中状態をロールバックし、エラー封筒と代替入口を残す。

05 COMMIT一度だけ次へ

履歴・画面・台帳を一操作一commit。解除・戻る・再開でview stateを復元。

非同期の不変条件

  • current term以外の応答は現在の地図を上書きしない。
  • 一つの操作に一つのcommit。hoverや途中失敗で履歴を増やさない。
  • 空結果は停止ではなくnoMissの次の入口へ。

surfaceの不変条件

  • Context / Menu / Actionを同じSurface Managerで管理。
  • close後は直前の探索面へ戻り、初期状態へリセットしない。
  • モバイルではContextを固定dockからページフローへ移し、Mapを隠さない。

検証された回帰面

  • stale operation、combine resilience、menu resilience。
  • ledger return / route return / state consistency。
  • mobile surface、canvas real click、universal menu。

次の判断：前編を閉じて後編へ移る条件

NOW / 前編の閉鎖

人間による効果検証

  • 問いを持つ利用者が最初の出典へ到達できる。
  • 候補・証拠・解釈・判断の違いを説明できる。
  • 台帳を保存して再開し、プロジェクトへ再利用できる。
  • 操作停止時に、処理中/失敗理由/次の行動が見える。

反証: 既定操作だけが支配し、成果物が残らず、利用者が境界を誤解する。

NEXT / 後編の基盤

原典・版・翻訳alignment

  • 原語、翻訳、版、訳者、年、標準ロケータを第一級化。
  • 短句から引用・段落へ同じ台帳エントリを接続。
  • 保存/欠損/追加/変容を版ごとに比較。
  • 著作・人物は普通名詞の語源処理から分岐。

条件: 証拠階層と人間の採用判断がUIに残る。
